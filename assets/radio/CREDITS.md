# The radio's music: licences and credits

The stations (`content/radio/stations.yaml`) play the files in this folder, one folder per station. Every track
must be credited here, and **the game needs a credits screen that lists them before it's released** (CC BY's
condition; the radio's readout shows each track's title and artist as it plays, which isn't enough on its own).

Check each file's licence before adding it. After adding, replacing or removing a file, run `npm run radio:index`.
